# How are drones used for aerial imagery purposes?
- Applications: search and rescue, agriculture, law enforcement, environmentalism
- Competitions
- Aerial imagery types:
  - angle: oblique (side angle) vs nadir (top-down)
  - color: RGB-D, multi-spectral, plain RGB
- example:
  - autonomous navigation of multi-copter drones (that need continuous control)
  - path planning and obstacle avoidance
  - local only (no external compute/telemetry/GPS)
  - process:
    - take VIO + RGB-D
    - privileged learning and deep reinforcement learning for optimal trajectories (Unity, Flightmare, Stable Baselines)
    - output yaw rate, forward velocity, vertical velocity
    - zero-shot for new drone and environment
  - gimbal cameras for stabilized images

# OpenCV for computer vision and club?
- OpenCV: general-purpose computer vision library
- FOSS with Python and C++ bindings
- has: feature detection, 3D reconstruction, motion analysis, optical flow, photo manipulation/de-blur/refining
- video editing/read/write
- install process
  - install `python`
  - install `pip`
  - install `opencv-python`
  - make test program
- previous uses for team:
  - feature detection (ORB, SIFT), feature matching, image manipulation

# Pre-made alternatives?
- OpenDroneMap
  - give images with geo tags
  - adjust 50 parameters
  - let program stitch together
- Benefits:
  - simple (plug and play)
  - nice API
  - coding avoidable
  - interesting extra data (3D model)
- Detriments:
  - not optimized for in-flight
  - slow unless optimized
  - requires accurate GPS tags
  - too feature-rich
