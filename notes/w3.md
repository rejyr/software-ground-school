# opencv object detection
- many filtering methods to isolate objects
- blur and level curs to reduce noise
- consider `cv.findCountours()` to filter with advanced parameters
- SimpleBlobDetector basic for blobs, some parameters to adjust, fails for more complex objects
# neural networks
- graph of neurons
- neurons are simple functions, apply weighted "activation function" to input nodes
- learn by adjusting node weights
- move in gradient of less loss (gradient descent)
- learn by running data through, update parameters for better result
- tensorflow demo
  - can memorize training data (higher testing loss)
  - overfitting booo
- video
  - reinforcement learning (train with simulation data)
  - farther distance is greater fitness
# Convolutional Neural Networks (CNNs)
- type of NN
- applies convolutional kernel (predetermined matrix) to image (sliding across) to extract features
- pooling to aggregate values into smaller matrices
- SOEP etc. for small object detection
# working with models
- collect data
  - needs hella data (Big Data around covid)
  - to be robust and cover many cases
  - don't give too many same images to avoid overfitting
- annotate with more expensive algorithm (SAM)
- preprocess data for easier training (exposure, hue, etc.)
